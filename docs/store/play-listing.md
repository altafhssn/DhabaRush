The Hindi name is the brand line from the feature graphic ("Highway Idle Tycoon"), not a word-for-word copy of the English name. Do not change it to "इंडियन आइडल टाइकून": in Devanagari "Idle" and "Idol" are both spelled आइडल, so "इंडियन आइडल" reads as the TV show *Indian Idol* (a trademark). The shorter fallback is "ढाबा रश: आइडल टाइकून" (20). A name with "बिज़नेस गेम" ("ढाबा रश: हाईवे ढाबा बिज़नेस गेम") is 31 code points, one over the limit, so the term sits in the first line of the description instead.

The tone follows `docs/launch/hindi.md` §2: everyday Hindi, polite imperative (करें, रखें, बनाएँ), and the words the game uses on screen (स्टाफ़, मुसाफ़िर, गल्ला, मुंशी जी, "ऐड हटाएँ", बोनस, ढाबा कैश). The listing has "बिज़नेस गेम" once (first line) and one Roman-script line (line 3, for the many Hindi-locale players who type in Roman script). Earnings words are left out here too: the away-pay line says बिक्री (sales), not कमाई. Get one native-speaker read before publishing (C8.5; it goes on the review sheet that the Hindi pass regenerates once the English is final).

The English and Hindi full descriptions have the same number of non-empty lines (40 each), so the review sheet (`docs/hindi-review/make_review.py`) pairs them line by line. Keep it that way when either changes.
