This page is the copy to paste into Play Console. Counts are Unicode code points, the strictest way to count. Play's own counter may show fewer for Hindi, because it can count a letter and its vowel sign as one character.

The Hindi name is the brand line from the feature graphic ("Highway Idle Tycoon"), not a word-for-word copy of the English name. Do not change it to "इंडियन आइडल टाइकून": in Devanagari "Idle" and "Idol" are both spelled आइडल, so "इंडियन आइडल" reads as the TV show *Indian Idol* (a trademark). The shorter fallback is "ढाबा रश: आइडल टाइकून" (20).

The tone follows `docs/launch/hindi.md` §2: everyday Hindi, polite imperative (करें, रखें, बनाएँ), and the words the game uses on screen (स्टाफ़, मुसाफ़िर, गल्ला, मुंशी जी, "ऐड हटाएँ"). Get one native-speaker read before publishing; it can join the review list for `i18n/hi.po`.

## 3. Keyword notes

From `docs/aso.md` §3, applied to Play. Play gives the title the most weight, then the short description, then the full description, and penalises stuffing, so each keyword sits in a normal sentence.

| dhaba (own-able: no idle dhaba game on Play) | Title, short description, full description 4 times |

| chai, truck, roti, paratha, lassi, paneer | Short (chai, truck), full (the dish list) |

Left out on purpose: competitor names, "free", "best", "#1", "3D simulator" and lists of other genres. The week the listing goes live, rerun `tools/aso/store_scrape.py playsearch "dhaba game" "idle dhaba" "highway tycoon"` and track those three queries.

## 5. Claims to keep true (or change the copy)

Every promise above is in the code today. If one of these changes, edit the listing in the same release.

| Promise | Where it lives |
|---|---|
| 4 counters, 16 dishes, unlocked by levelling up | `data/economy_v3.json` stations → `menu` (`from_level` 25 / 50 / 100) |
| Waiters carry the whole order in one trip | `data/economy_v3.json` `waiters` (whole-order rule) |
| Up to 3 waiters, 2 cashiers, 3 cooks per counter, 5 tables | `Game.waiter_max()`, `Game.galla_max()`, `Layout3.MAX_STATION_STAFF`, `tables_max` |
| Lorries park, buses stop, autos, cars and bikes pass | `scripts/v3/world/traffic.gd` vehicle kinds (tractor kind exists but has no model, so it never spawns) |
| Day and night with fairy lights | `daynight` block, `scripts/v3/world/day_night.gd` |
| Away pay from 10 min, up to 2 h, ×2 ad from 30 min | `offline`: `min_away_s` 600, `cap_hours` 2, `rate` 0.25, `ad_min_away_s` 1800 |
| Tasks pay cash; every 10 tasks fill a chest | `tasks`: `chest_claims` 10 |
| Interstitials: not before session 4, at most one a minute, only when an upgrade panel closes after a purchase | `config/monetization.cfg` [ads] |
| Remove Ads stops interstitials; rewarded ads stay optional | `scripts/autoload/ads.gd` `interstitial_block_reason()` |
| VIP doubles every sale | `Game.income_mult()` (`vip_mult` 2.0) |
| English and Hindi, switch in Settings | `scripts/autoload/loc.gd`, the Settings LANGUAGE row |
| Lakh and crore | `Fmt` and the Settings INDIAN NUMBERS toggle (on by default on Indian locales) |
| LOW graphics mode | Settings GRAPHICS (`scripts/v3/core/gfx_quality.gd`) |
| Progress saved on the phone | `user://save3.json`; there is no cloud save |
| **Play offline: no internet needed** | **Not yet checked on a phone.** Before publishing, install the internal-test build, turn on airplane mode, cold-start and play for 5 minutes. If anything blocks (consent, billing, a hang), delete that bullet in both languages and the Offline tag |

Do not add "Made in India" unless the studio is registered in India (`docs/aso.md` §10). Do not mention sikke: the sikke pill and the shop are switched off in v0.3, so players can neither see nor spend them.
